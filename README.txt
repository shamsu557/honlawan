LHD Constituency website — updated October 2026

Open index.html in a browser or upload the contents of this folder intact to your web hosting.

Improvements:
- Ward Explorer has the 12 official Dala wards by name, description, and links to ward-filtered records.
- The searchable local registry supports project name, number, ward, description keywords, category, status, and year (1999–2026).
- Ward and category checkbox filters work on the constituency explorer and show project record cards.
- Displayed year range is 1999–2026. Existing project years remain their actual documented/demo values.
- Supplied photograph-caption records added without inventing dates or serial numbers.

IMPORTANT DATA LIMITATIONS:
- This is still a static site (no server/database or independently validated project registry). Search works across only the included local project-data.js records. Add verified projects to that file to expand results.
- Original sample slideshow project serial numbers are retained as source-provided, not independently verified.
- No real GIS boundaries or surveyed project coordinates were supplied; the ward selector is clearly labelled schematic, not a geographic map.
- The original website's other static dashboard statistics are not independent verification of real project totals.
- Dala ward names cross-checked against INEC Nigeria 2015 polling unit directory: https://www.inecnigeria.org/wp-content/uploads/2019/02/PU_Directory_Revised_January_2015_Kano.pdf
